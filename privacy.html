2. Que dados pessoais são recolhidos

Este website pode recolher dados pessoais quando um visitante decide entrar em contacto através do formulário de contacto.

Os dados solicitados pelo formulário são:

  • Nome
  • Email
  • Empresa, quando fornecida
  • Tipo de projeto
  • Mensagem

O preenchimento dos campos necessários é voluntário, mas alguns dados são necessários para que seja possível responder ao pedido enviado.

3. Para que utilizo os seus dados

Os dados enviados através do formulário são utilizados para responder a pedidos de contacto e de informação relacionados com serviços de desenvolvimento web.

Poderão também ser utilizados para compreender as necessidades apresentadas, avaliar a viabilidade de um projeto e, quando solicitado, preparar uma proposta ou orçamento.

Os dados não são utilizados para criar perfis comerciais ou para publicidade dirigida através deste website.

4. Fundamento jurídico

Quando o contacto é realizado com o objetivo de obter informações ou iniciar conversações relacionadas com a contratação de um serviço, o tratamento dos dados poderá basear-se na realização de diligências pré-contratuais a pedido do titular dos dados, nos termos do artigo 6.º, n.º 1, alínea b), do Regulamento Geral sobre a Proteção de Dados (RGPD).

Quando outra base jurídica for aplicável às circunstâncias concretas do tratamento, esta será determinada de acordo com o RGPD e a legislação aplicável.

5. Como os dados são enviados

O formulário de contacto utiliza o serviço Web3Forms para processar tecnicamente os dados enviados e encaminhá-los para o endereço de email associado ao formulário.

De acordo com a informação publicada pelo próprio Web3Forms, o serviço não armazena permanentemente as submissões dos formulários, embora possa existir informação em logs técnicos que seja eliminada periodicamente.

O Web3Forms informa também que os seus servidores estão localizados na região US-East, nos Estados Unidos.

Para obter informação atualizada sobre o tratamento realizado pelo fornecedor, consulte a documentação e a política de privacidade do Web3Forms.

6. Prazo de conservação

Os dados enviados através do formulário serão conservados apenas durante o período necessário para responder ao pedido e gerir eventuais contactos relacionados com o projeto.

Na ausência de uma relação contratual ou de outra necessidade legítima de conservação, os dados serão, em regra, eliminados até 12 meses após o último contacto.

Este prazo poderá ser superior quando a conservação for necessária para cumprir obrigações legais, exercer ou defender direitos ou tratar uma questão ainda em curso.

7. Direitos dos titulares dos dados

Nos termos da legislação aplicável, poderá exercer, consoante as circunstâncias, os direitos de:

  • Acesso aos seus dados pessoais;
  • Retificação de dados inexatos ou incompletos;
  • Apagamento dos dados;
  • Limitação do tratamento;
  • Oposição ao tratamento;
  • Portabilidade dos dados, quando aplicável.

Para exercer qualquer destes direitos, entre em contacto através de:

thiagohitalo74@gmail.com

8. Cookies e armazenamento local

Este website não utiliza atualmente cookies não essenciais para publicidade ou análise comportamental.

O website utiliza o armazenamento local do navegador (localStorage) para guardar a preferência de idioma escolhida pelo visitante, permitindo que essa preferência seja mantida entre visitas.

Esta informação é armazenada localmente no dispositivo do visitante e não é utilizada para criar perfis publicitários.

9. Serviços de terceiros

Google Fonts

Web3Forms

O formulário de contacto utiliza o Web3Forms para processar e encaminhar as mensagens enviadas.

10. Segurança

São adotadas medidas técnicas e organizativas razoáveis para proteger os dados pessoais tratados através deste website contra acesso, alteração, divulgação ou destruição não autorizados.

Apesar disso, nenhum sistema de transmissão ou armazenamento de informação através da Internet pode garantir segurança absoluta.

11. Alterações a esta política

Esta Política de Privacidade poderá ser atualizada sempre que necessário, nomeadamente quando forem introduzidos novos serviços, funcionalidades ou alterações relevantes no tratamento de dados.

A versão mais recente estará sempre disponível nesta página.
